Objetivo

Este repositório foi criado para praticar o controle de versões utilizando o GitHub, incluindo commits, branches, Pull Requests e revisão de código.

## Sobre o repositório

Este projeto faz parte de uma atividade prática da disciplina de Engenharia de Software. Seu propósito é demonstrar o uso do GitHub para registrar alterações, organizar o desenvolvimento em branches e revisar mudanças por meio de Pull Requests.
